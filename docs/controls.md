# Native controls

The port retains native controller input and the original game's menus and
control scripts. Loading a place does not replace gameplay with keyboard mode.

The shared vehicle controller covers forward/reverse, steering, cancelled input,
seat transfers, seat exit and respawn. The actual controls and core gameplay of
each original place still need testing on Vita.

Loader controls follow the existing native button hints and current confirm /
cancel preference. Existing avatar idle animations and Xbox interface feedback
assets remain in use.
