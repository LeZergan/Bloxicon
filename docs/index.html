Current state

This source tree covers the native Vita client and its shared compatibility changes. The Vita smoke test checked repeat loading and native controls in Crossroads v2. Live portraits and place preview retention were also verified on Vita.

Compatibility

Original places must run directly from their original bytes. A complete pass requires working menus, native controls, core gameplay, scripts/assets, usable performance and repeated loading without a crash.

Presentation

The loader retains existing avatar idle animations and dependencies, current audio preferences and existing interface feedback assets.

Known limits

  • Clean installation and broader Vita gameplay acceptance remain pending.
  • Known class/property gaps remain.
  • Headless loading is a partial result.
  • Source distribution and dependency bootstrap are separate unfinished work.
